# ProofScore Frontend Dashboard

The Next.js frontend dashboard for ProofScore - a verifiable on-chain reputation engine.

## Features

- Interactive dashboard for checking wallet reputations
- Real-time score visualization
- Detailed metrics display
- Proof verification components

## Environment Variables

Create `.env.local` with:

- `NEXT_PUBLIC_API_URL`: Backend API URL (default: http://localhost:3001)

## Scripts

- `npm run dev`: Start development server
- `npm run build`: Build for production
- `npm run start`: Start production server
- `npm run lint`: Run ESLint

## Pages

- `/`: Landing page with project overview
- `/dashboard`: Main dashboard for checking wallet reputations
- `/api-docs`: API documentation page
